# 🤖 My Automation Agent

A full-stack AI-powered automation dashboard to manage social media content publishing and client communications. Built to automate repetitive tasks like posting videos, sending WhatsApp messages, and making voice calls.

##  Features

### 📱 Multi-Account Management
- Add and manage multiple social media accounts (YouTube, LinkedIn, Instagram, Twitter).
- Categorize accounts as Personal, Client, or Business.
- Select specific accounts while scheduling posts.

### 📹 Content Publishing
- **Bulk Upload:** Upload a CSV file to schedule multiple posts at once.
- **Manual Add:** Add single posts/videos with custom captions and schedule times.
- **Real-time Tracking:** Track status from "Ready" ➡️ "Uploading" ➡️ "Published".

### 📞 Client Communication (Twilio Integrated)
- **WhatsApp Automation:** Send automated messages to clients.
- **Voice Calls:** Trigger automated voice calls.
- **Smart Routing:** Automatically switch between Email, WhatsApp, or Call based on client preference.

### 🎨 Modern UI/UX
- Beautiful Dark Theme dashboard.
- Fully responsive (Mobile & Desktop).
- Interactive modals and real-time status badges.

## ️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, Vanilla JavaScript, Bootstrap 5
- **APIs:** Twilio (WhatsApp & Voice Calls)
- **Deployment:** Render
